# Skills seeded into executor directories

`handoff/SKILL.md` is adapted from the `handoff` skill in https://github.com/mattpocock/skills (MIT License,
Copyright (c) 2026 Matt Pocock). Changes: it can be invoked by the model (the pipeline asks for it in plain words, since slash syntax differs per CLI), the document is saved to `.agentd/HANDOFF.md` in the executor's directory,
it has a fixed list of sections, and it replies with only the path.

The five-section layout follows the idea of the `handoff` skill in https://github.com/ykdojo/claude-code-tips, whose
repository carries no open-source licence ("All Rights Reserved"), so its text is not copied.
